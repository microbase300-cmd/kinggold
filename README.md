# Obinna Joseph Okwudiri (King Gold) — Founder @ Microbase | Executive Portfolio

Official Developer, Systems Architect, and Founder Portfolio for **Obinna Joseph Okwudiri** (*King Gold*), Founder of **Microbase**.

## Overview
Engineered with a high-contrast, terminal-inspired obsidian dark mode (`#090A0F` background, `#12141D` cards, `#F59E0B` subtle gold accents, and `#10B981` status indicators), this portfolio showcases the technical doctrine, sovereign infrastructure capabilities, and strictly anonymized R&D initiatives of the **Microbase** ecosystem.

## Tech Stack
- **Framework:** Vite + React 19 + TypeScript
- **Styling:** Tailwind CSS (`@tailwindcss/vite`)
- **Animations & Iconography:** Framer Motion + Lucide React
- **Typography:** Inter + JetBrains Mono
- **Deployment:** Vercel SPA Configuration ([`vercel.json`](./vercel.json))

## Architecture Modules
- [`src/components/Navbar.tsx`](./src/components/Navbar.tsx) — Live UTC telemetry header and system node status indicator
- [`src/components/Hero.tsx`](./src/components/Hero.tsx) — Executive identity, core metrics, and live execution bus console
- [`src/components/FounderVision.tsx`](./src/components/FounderVision.tsx) — Founder's profile, Microbase Core Vision & Mission statements, and architectural pillars
- [`src/components/TechBento.tsx`](./src/components/TechBento.tsx) — Four-pillar capability bento grid (Full-Stack & Mobile, Bare-Metal & MTA Infrastructure, Agentic AI & QLoRA Fine-Tuning, Quantitative Trading & MQL5/Pine Script)
- [`src/components/SystemsShowcase.tsx`](./src/components/SystemsShowcase.tsx) — Filterable, expandable architectural blueprints with strict OPSEC project anonymization
- [`src/components/ContactFooter.tsx`](./src/components/ContactFooter.tsx) — Interactive executive transmission terminal and footer
